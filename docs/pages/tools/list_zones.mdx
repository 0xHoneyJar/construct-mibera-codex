<ToolCard n={6} name="list_zones" purpose="every canonical zone — discovery surface" />

returns an array of `{slug, name, emoji, archetype}`. use it to discover canonical slugs before [`lookup_zone`](/tools/lookup_zone), or to validate that a zone reference in agent prose maps to a real slug.

## Input

```json
{}
```

no arguments. (the MCP SDK requires `arguments: {}` to be present even when empty.)

## Output

```json
[
  { "slug": "stonehenge", "name": "Stonehenge", "emoji": "🪨", "archetype": "All" },
  { "slug": "bear-cave",  "name": "Bear Cave",  "emoji": "🐻", "archetype": "Freetekno" },
  ...
]
```

## Composition

| pair this with | for |
| --- | --- |
| [`lookup_zone`](/tools/lookup_zone) | drilling into a specific zone's full entry |
| [`validate_world_element`](/tools/validate_world_element) | the inverse — "is this slug canonical?" |
