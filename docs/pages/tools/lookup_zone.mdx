> 🔒 **HARD tier.** zone slugs are canonical. look them up, don't invent.

returns name, emoji, archetype anchor, era resonance, essence, lynch primitives (paths, edges, districts, nodes, landmarks), KANSEI tokens (warmth, motion, shadow, easing, density, sound). null if the slug isn't canonical.

## input

```json
{ "slug": "stonehenge" }
```

| field | type | required | notes |
| --- | --- | --- | --- |
| `slug` | `string` | ✅ | canonical zone slug — see [`list_zones`](/tools/list_zones) |

vocabulary, not script. the agent composes from these primitives — never dump the whole entry.

## non-canonical

```json
null
```

null means null. fall back to [`validate_world_element`](/tools/validate_world_element) with `type: "zone"` for a fuzzy-match suggestion.

## composition

| pair this with | for |
| --- | --- |
| [`list_zones`](/tools/list_zones) | discovering canonical slugs before lookup |
| [`validate_world_element`](/tools/validate_world_element) | recovering from typos or non-canonical input |
| [`lookup_archetype`](/tools/lookup_archetype) | following the zone's `archetype` field |

## edge cases

- `"All"` is a real archetype value for cross-archetype zones (stonehenge). don't filter it out.
- deprecated zones return `null`. the codex doesn't carry tombstones.
- case-sensitive — `"Stonehenge"` ≠ `"stonehenge"`. always lowercase.
