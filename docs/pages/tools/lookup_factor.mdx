# Network Mysticism

Twenty-eight factors. Each one a signal score-mibera emits when it sees an on-chain action — a mint, a stake, a burn, a long-form article. The codex translates the signal into lore: which archetype it anchors, what cultural register it carries, what the activity *means* in the world. Agents read this canon through `lookup_factor` →
