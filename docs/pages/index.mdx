## the eight

| call | returns |
| --- | --- |
| `lookup_mibera(id)` | full trait set for one of the ten thousand |
| `lookup_archetype(name)` | era, locations, figures, fashion for one tribe |
| `lookup_grail(query)` | a 1/1 grail by id, slug, or name |
| `lookup_factor(factor_id)` | score-mibera factor ↔ codex lore |
| `lookup_zone(slug)` | zone entry, lynch primitives, KANSEI tokens |
| `list_archetypes()` | the four tribes |
| `list_zones()` | every canonical zone |
| `validate_world_element(t, v)` | canonical check, fuzzy match, coverage-gap log |

## what the codex doesn't do

- it doesn't write. the codex repo is the only writer.
- it doesn't talk. it returns json. your agent makes prose.
- it doesn't police voice. only [HARD-tier](/anti-hallucination) claims must look up; everything else stays open.
