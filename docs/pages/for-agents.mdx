## What the Agent Will Do

A single conversation through your AI client, after the skill is loaded:

```
you   → tell me about mibera 1606
agent → lookup_mibera(1606)
codex → { id: 1606, traits: { background: "Pluto", outfit: "...", ... } }
agent → "1606 wears Pluto on its back — the underworld grail. Dust-toned
        outfit, eyes pointed at the abyss. One of the seven planet-grail
        carriers..."
```

Without the skill, the agent might invent traits or misspell tribes. With it, every name resolves to canon.
