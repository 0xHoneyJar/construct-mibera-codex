# For Agents

Want your AI agent to read the Mibera codex? Give it this skill.

<div className="skill-link">

Paste this URL into your AI agent. It loads the codex's purpose, MCP endpoint, and the eight read-only tools — your agent grounds every claim in canonical Mibera lore instead of inventing.

## What the Agent Will Do

A single conversation through your AI client, after the skill is loaded:

```
you   → tell me about mibera 1606
agent → lookup_mibera(1606)
codex → { id: 1606, traits: { background: "Pluto", outfit: "...", ... } }
agent → "1606 wears Pluto on its back — the underworld grail. Dust-toned
        outfit, eyes pointed at the abyss. One of the seven planet-grail
        carriers..."
```

Without the skill, the agent might invent traits or misspell tribes. With it, every name resolves to canon. The full skill document — including all eight tools, the anti-hallucination tier model, and three example conversations — is at <a href="/skill.md"><code>/skill.md</code></a>.
